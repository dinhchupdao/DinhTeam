## ✨ Điểm Nổi Bật & Tính Năng (Key Features)

- **Aesthetic Obsidian & Gold Luxury Theme**: Thiết kế chuẩn quốc tế với tone màu đen sâu huyền bí (Obsidian) kết hợp điểm nhấn vàng ánh kim (Champagne Gold), hiệu ứng kính mờ (Glassmorphism) tinh xảo.
- **Interactive Lightbox Modal**: Trải nghiệm xem ảnh toàn màn hình độ phân giải cao kèm thông số EXIF ống kính (Leica M11, Sony A1, tiêu cự, khẩu độ, ISO) và điều hướng phím mũi tên.
- **Dynamic Category Filter**: Phân loại tác phẩm linh hoạt theo chủ đề (*Fashion & Editorial, Fine Art Portrait, Cinematic Wedding, Architecture, Film Noir*).
- **Interactive Before & After Retouch Slider**: Thanh trượt so sánh trực quan giữa ảnh chụp gốc (RAW flat capture) và bản hoàn thiện màu sắc điện ảnh (Master Color Graded).
- **Interactive Web Audio Synth Shutter**: Hiệu ứng âm thanh màn trập cơ học của máy ảnh chân thực khi tương tác (tùy chọn Bật/Tắt).
- **Bespoke Pricing Packages**: Bảng giá dịch vụ rõ ràng (*Fashion & Lookbook, Signature Portraiture, Cinematic Wedding*) tự động liên kết điền nhanh vào form đặt lịch.
- **Interactive Booking Form & Toast**: Form đặt lịch chụp trực quan với thông báo xác nhận sang trọng.
- **Mobile Responsive & SEO Optimized**: Tương thích hoàn hảo mọi thiết bị (Desktop, iPad, Mobile) cùng cấu trúc thẻ Meta SEO và Open Graph chuẩn mực.

## 🚀 Hướng Dẫn Tải Lên GitHub (How to Push to GitHub)

### Bước 1: Khởi tạo Git & Commit trên máy tính
Mở Terminal / PowerShell tại thư mục này và chạy các lệnh sau:

```bash
# 1. Khởi tạo Git repository (nếu chưa có)
git init

# 2. Thêm toàn bộ file vào stage
git add .

# 3. Tạo commit đầu tiên
git commit -m "feat: initial commit for DINH STUDIO luxury photography website"
```

### Bước 2: Tạo Repository trên GitHub
1. Truy cập [github.com/new](https://github.com/new).
2. Đặt tên Repository (ví dụ: `dinh-photographer-portfolio` hoặc `DinhTeam`).
3. Chọn chế độ **Public** hoặc **Private**.
4. **Không** tích chọn *"Add a README file"* (vì dự án đã có sẵn).
5. Bấm **Create repository**.

### Bước 3: Liên kết và Đẩy (Push) lên GitHub
Copy lệnh từ GitHub và chạy:

```bash
# Đổi tên nhánh chính thành main
git branch -M main

# Liên kết với repository GitHub của bạn (thay link repo tương ứng)
git remote add origin https://github.com/<tai-khoan-github-cua-ban>/<ten-repository>.git

# Đẩy mã nguồn lên GitHub
git push -u origin main
```

## 🌐 Triển Khai Miễn Phí Trên GitHub Pages

1. Vào repository trên GitHub của bạn, chọn **Settings** > **Pages** (cột bên trái).
2. Tại mục **Branch**, chọn nhánh `main` và thư mục `/ (root)`.
3. Bấm **Save**.
4. Sau 1 - 2 phút, website của bạn sẽ hoạt động trực tiếp tại địa chỉ:  
   `https://<tai-khoan-github-cua-ban>.github.io/<ten-repository>/`
